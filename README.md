# UB – Unterrichtsbeobachtung

Web-App für Unterrichtsbesuche (iPad-optimiert), basierend auf dem Feedbackbogen „UB-Vorlage“.

- Verlaufsprotokoll mit Stoppuhr, Beobachtungsraster, Notizen, Tafelbild (Foto + Skizze)
- Export: PDF (Drucken), Markdown (Obsidian), JSON-Backup
- **Alle Daten bleiben lokal im Browser des Geräts** – nichts wird an einen Server gesendet.
- Offline nutzbar: in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
